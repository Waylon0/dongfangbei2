# 断层多边形自动追踪系统 — 软件设计说明

## 1. 项目概述

### 1.1 项目背景
本项目为第十二届"东方杯"全国大学生勘探地球物理大赛赛题7的参赛作品。赛题要求基于平面断层属性数据，设计并实现一种高效的断层多边形自动追踪方法，提升构造解释的自动化水平。

### 1.2 核心目标
- 从平面断层属性数据中自动识别断层区域
- 将断续的断层片段沿走向连接成完整断层
- 生成闭合的断层多边形
- 支持面积统计与阈值过滤
- 合理处理断层之间的交切关系

## 2. 系统架构

### 2.1 整体架构
系统采用**算法核心 + 交互前端**的分层架构：

```
┌─────────────────────────────────────┐
│         Streamlit 前端 (app/)        │
│  侧边栏 │ 分步演示 │ 参数调节 │ 探索 │
├─────────────────────────────────────┤
│          桥接层 (app/pipeline/)      │
├─────────────────────────────────────┤
│          算法核心 (src/)             │
│  预处理 → 分割 → 追踪 → 提取 → 矢量化 │
├─────────────────────────────────────┤
│          参数配置 (config.py)        │
└─────────────────────────────────────┘
```

### 2.2 设计原则
- **算法与展示分离**：`src/` 为纯算法模块，不依赖 Streamlit
- **参数可调**：所有算法参数集中在 `config.py`，前端可通过滑块实时调节
- **中间数据保留**：流水线每步输出中间结果，供分步展示和调试

## 3. 算法设计

### 3.1 流水线总览
输入 → 预处理 → 二值分割 → 形态学处理 → 断层追踪 → 轮廓提取 → 矢量简化 → 面积过滤 → 输出

### 3.2 各步骤详细设计

#### 步骤1：预处理 (`src/preprocess.py`)
- 归一化到 [0, 1]
- 可选 CLAHE 对比度增强
- 高斯滤波去噪（σ 可调）

#### 步骤2：二值分割 (`src/segment.py`)
两种模式：
- **全局 Otsu 阈值**：自适应计算全局阈值，支持缩放因子调节敏感度
- **局部自适应阈值**：对响应强度空间变化大的数据更鲁棒，使用局部高斯加权阈值

#### 步骤3：形态学处理
- 闭运算（填充孔洞、连接断缝）
- 开运算（去除噪点）

#### 步骤4：断层追踪 (`src/tracker.py`) — **核心创新**
这是本系统的核心算法，解决断续断层的自动连接问题：

1. **骨架化**：对二值图做骨架化，得到1像素宽的断层中心线
2. **片段分割**：在交叉点（度数≥3）处断开骨架，得到独立的曲线片段
3. **走向估算**：对每个片段用 PCA 估算端点走向，端点延伸到区域边界
4. **图模型匹配**：
   - 候选连接代价 = 空间距离 + 方向不一致惩罚 + 梯度方向验证
   - 方向验证：端点走向需指向对方，且沿连接线采样的梯度方向一致
5. **贪心连接**：按代价从小到大依次连接，每个端点最多连一次
6. **膨胀恢复**：连接线膨胀恢复断层宽度，限制在原始区域走廊范围内

#### 步骤5：交叉断层分离 (`src/polygon_extract.py`)
基于方向聚类的智能分离：
1. 骨架化 → 找交叉点
2. 在交叉点断开骨架，得到独立片段
3. PCA 估算每段走向
4. 方向一致的片段归为同一断层（并查集聚类，夹角阈值45°）
5. 每组片段膨胀回原区域

#### 步骤6：轮廓提取
- 对每个分离后的区域用 Marching Squares 算法提取闭合轮廓
- 高斯平滑减少锯齿

#### 步骤7：矢量简化 (`src/vectorize.py`)
- Douglas-Peucker 折线简化（容差可调）
- Chaikin 角点切割平滑（迭代次数可调）

#### 步骤8：面积过滤
- Shoelace 公式计算面积
- 按用户设定的面积阈值过滤小多边形

### 3.3 多尺度融合 (`src/multiscale.py`)
- 在不同高斯σ下分别运行完整流水线
- 细尺度捕捉细节，粗尺度连接断缝
- 用 IoU（交并比）去重：按面积从大到小，移除与已保留多边形高度重叠的结果

## 4. 前端设计

### 4.1 技术选型
- **Streamlit**：快速构建交互式数据应用
- **Plotly**：高性能交互式图表

### 4.2 页面设计
| 页面 | 功能 | 核心组件 |
|------|------|----------|
| 首页 | 数据加载 + 结果预览 | 热力图 + 多边形叠加 |
| 分步流水线 | 7步可视化 + AI语音讲解 | 进度条 + 步骤描述 + Plotly图表 |
| 参数调节 | 滑块调参 + 自动刷新 | 参数面板 + 实时结果图 |
| 交互探索 | 全屏地图 + 点击详情 | Plotly交互地图 + 多边形列表 |
| 结果对比 | 双参数集并排对比 | 独立参数面板 + 对比图 |

### 4.3 深色主题
使用自定义CSS实现科技感深色界面，配色：青色(#00E5FF) + 紫色(#7B2FBE)。

## 5. 数据流

```
.npy/.npz 文件
    ↓ load_attribute_data
2D numpy 数组 (H, W)
    ↓ preprocess
归一化 + 平滑数据
    ↓ segment_fault_regions
二值掩膜 (0/1)
    ↓ track_faults
连接后的二值掩膜
    ↓ extract_fault_polygons
轮廓列表 [([(r,c),...]), ...]
    ↓ simplify_polygon
简化多边形 [(N,2) array, ...]
    ↓ filter_by_area
过滤后多边形 + 面积列表
    ↓ export_geojson / export_polygons_txt
GeoJSON / TXT 文件
```

## 6. 性能设计
- 核心算法在1分钟内完成（300×400数据实测 < 1秒）
- Streamlit 缓存避免重复计算
- 内存使用合理，无全局状态累积

## 7. 扩展性
- **GeoEast 集成**：`src/preprocess.py` 中的 `load_attribute_data` 可扩展为读取 GeoEast 数据库；`src/vectorize.py` 中的导出函数可扩展为写入 GeoEast 数据库
- **打包部署**：支持 `pyinstaller -F main.py` 打包为可执行文件，集成到 GeoEast 虚拟机菜单
- **新算法接入**：算法模块独立，可替换任意步骤的实现
