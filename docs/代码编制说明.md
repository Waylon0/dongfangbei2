## 2. 核心模块说明

### 2.1 config.py — 参数配置
所有算法参数集中定义，类型标注明确。前端 `param_controls.py` 从此文件同步参数定义。

| 参数组 | 关键参数 | 说明 |
|--------|----------|------|
| 预处理 | `gaussian_sigma` | 高斯滤波σ，控制去噪强度 |
| 分割 | `otsu_scale` / `use_adaptive_threshold` | 全局阈值缩放 / 局部自适应阈值开关 |
| 追踪 | `track_max_link_distance` / `track_angle_weight` | 最大连接距离 / 方向权重 |
| 提取 | `separate_intersections` / `min_component_area` | 交叉分离开关 / 最小面积 |
| 简化 | `dp_epsilon` / `smooth_iterations` | DP容差 / Chaikin迭代 |
| 多尺度 | `scales` / `dedup_overlap_threshold` | σ列表 / IoU去重阈值 |

### 2.2 src/tracker.py — 断层追踪
核心类和函数：
- `SkeletonSegment`：骨架片段，封装端点、走向、边界延伸
- `track_faults()`：主入口，接收二值掩膜和可选原始数据
- `_connection_cost()`：连接代价 = 距离 + 方向惩罚 + 梯度验证
- `_check_gradient_consistency()`：沿连接线采样梯度方向一致性
- `_skeleton_to_segments()`：骨架→片段拆分
- `_order_points()`：无序点集→有序曲线（DFS）

### 2.3 src/polygon_extract.py — 轮廓提取
- `extract_fault_polygons()`：主入口
- `_separate_intersecting_faults()`：方向聚类分离（替代粗暴删像素）
- `_estimate_skeleton_direction()`：PCA 估算骨架走向
- `_cluster_by_direction()`：并查集方向聚类

### 2.4 src/segment.py — 区域分割
- 支持全局 Otsu 和局部自适应阈值两种模式
- 自适应阈值使用 `skimage.filters.threshold_local`（高斯加权）

### 2.5 src/multiscale.py — 多尺度融合
- `compute_iou()`：基于 Shapely 的 IoU 计算
- `deduplicate_polygons()`：面积优先贪心去重
- `merge_multiscale_results()`：多尺度结果合并

### 2.6 src/vectorize.py — 矢量简化与导出
- `douglas_peucker()`：DP 简化（支持闭合多边形）
- `chaikin_smooth()`：Chaikin 角点切割平滑
- `export_geojson()` / `export_polygons_txt()`：两种格式导出

### 2.7 src/utils.py — 公共工具
- `normalize()`：[0,1] 归一化
- `gradient_orientation()`：梯度幅值和方向
- `compute_local_direction()`：骨架点局部方向（PCA）
- `angle_between()`：向量夹角

## 3. 前端关键实现

### 3.1 参数隔离（04_结果对比.py）
对比页使用 `_render_isolated_params(prefix, cfg)` 为两组参数生成独立的 session_state key（`cmp_a_*` / `cmp_b_*`），避免参数共享问题。

### 3.2 自动调参（02_参数调节.py）
通过比较参数字典的哈希值检测变化，自动触发重新运行。

### 3.3 分步展示（01_分步流水线.py）
`run_pipeline_with_steps()` 保留每步中间数据（`binary_before_morph`、`binary_before_track`、`skeleton`、`junctions` 等），分步展示时按步骤号选择对应图表。

## 4. 依赖说明

| 库 | 版本 | 用途 |
|----|------|------|
| numpy | ≥1.24 | 数组运算 |
| scipy | ≥1.10 | 高斯滤波、形态学、距离变换 |
| scikit-image | ≥0.20 | Otsu阈值、自适应阈值、骨架化、轮廓提取 |
| networkx | ≥3.0 | 图算法 |
| shapely | ≥2.0 | 多边形IoU计算 |
| matplotlib | ≥3.7 | CLI可视化 |
| streamlit | ≥1.30 | 交互前端 |
| plotly | ≥5.18 | 交互式图表 |

## 5. 运行方式

```bash
# CLI 版本
python main.py

# Streamlit 交互版
streamlit run app/main.py --server.port 8501
```

## 6. 编码规范
- 类型标注：所有公开函数使用 type hints
- 文档字符串：每个模块和公开函数有中文 docstring
- 命名：函数/变量用 snake_case，类用 PascalCase
- 无全局可变状态，纯函数设计
